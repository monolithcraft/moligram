# ui

Интерфейс на QML. Три модуля, зависимости идут сверху вниз.

| Модуль | URI | Что внутри |
| --- | --- | --- |
| `screens` | `Moligram.Screens` | окно и панели: рейл, список чатов, чат |
| `controls` | `Moligram.Controls` | переиспользуемые элементы: кнопки, поля, иконки, пустые состояния |
| `design` | `Moligram.Design` | синглтон `Theme` с токенами цвета, отступов, шрифтов и движения; брендовые ресурсы |

Правила:

- цвета, отступы, радиусы и длительности анимаций берутся только из `Theme`;
- элементы `controls` не знают о данных и не хранят состояние приложения:
  получают свойства, отдают сигналы;
- иконки — пути SVG на сетке 20×20 в `Icons.qml`, рисуются через `Shape`
  и красятся токенами темы.
