# Дизайн

Moligram не повторяет облик официального клиента. Интерфейс — главное,
чем он отличается от других форков.

## Характер

Логотип задаёт всё: белое на чёрном, зерно и потёртость, сегментированный
ореол. Отсюда три правила:

1. **Монохром.** Цвет не украшает, а сообщает: ошибка, упоминание, запись.
   Всё остальное — оттенки серого.
2. **Тишина.** Интерфейс не спорит с сообщениями. Никаких градиентов,
   теней «для красоты» и обводок вокруг всего подряд.
3. **Точность.** Сетка 4 px, выверенная типографика, одинаковое поведение
   одинаковых элементов.

## Цвет

Тёмная тема по умолчанию. Все значения — токены модуля `Moligram.Design`,
экраны не содержат литералов цвета.

| Токен | Тёмная | Светлая | Назначение |
| --- | --- | --- | --- |
| `surface.base` | `#0A0A0B` | `#F4F3F1` | фон окна |
| `surface.raised` | `#111113` | `#FBFAF9` | панели, список чатов |
| `surface.overlay` | `#18181B` | `#FFFFFF` | меню, диалоги, входящие сообщения |
| `surface.hover` | `#FFFFFF` 4 % | `#000000` 4 % | наведение |
| `surface.inverse` | `#F2F2F3` | `#111113` | выбранный чат, исходящие сообщения |
| `line.subtle` | `#FFFFFF` 6 % | `#000000` 8 % | разделители |
| `text.primary` | `#F2F2F3` | `#111113` | основной текст |
| `text.secondary` | `#F2F2F3` 62 % | `#111113` 64 % | подписи, время |
| `text.tertiary` | `#F2F2F3` 40 % | `#111113` 42 % | плейсхолдеры |
| `tone.danger` | `#FF6B6B` | `#D63C3C` | ошибки, удалённое |
| `tone.mention` | `#E8E8E8` | `#111113` | упоминания (инверсный бейдж) |

Исходящие сообщения — светлые пузыри с тёмным текстом, входящие — тёмные.
Такой контраст узнаётся сразу и не требует цвета.

Режим OLED: `surface.base` становится `#000000`.
Акцентный цвет — опция в настройках, по умолчанию выключен.

## Типографика

- Интерфейс: **Inter** (OFL), включены `cv11`, `ss01`, табличные цифры для времени.
- Код и Message Shot: **JetBrains Mono** (OFL).
- Шкала: 11 / 12 / 13 / **14** / 16 / 20 / 28. Базовый размер — 14.
- Межстрочный интервал текста сообщений — 1.4.

## Форма

- Сетка 4 px. Отступы: 4, 8, 12, 16, 24, 32.
- Радиусы: 6 (поля, кнопки), 10 (карточки, меню), 16 (пузыри, окна).
- Пузыри без хвостиков. В серии сообщений внутренний угол уменьшается до 6.
- Тени только у плавающих слоёв (меню, диалоги), одна мягкая тень на тему.

## Компоновка

```
┌────┬──────────────┬─────────────────────────────┬────────────┐
│ ◯  │  Поиск  ⌘K   │  Имя чата · в сети          │            │
│ ◯  │──────────────│─────────────────────────────│  Профиль   │
│ ◯  │  Чат         │                             │  (по       │
│    │  Чат         │     сообщения               │  запросу)  │
│ ── │  Чат         │                             │            │
│ ▣  │  Чат         │  ┌───────────────────────┐  │            │
│ ▣  │              │  │ сообщение…            │  │            │
└────┴──────────────┴──┴───────────────────────┴──┴────────────┘
 рейл  список чатов         чат                     панель
```

- **Рейл (56 px):** аккаунты, папки, внизу — индикаторы Ghost Mode
  и Streamer Mode.
- **Список чатов:** ширина меняется перетаскиванием (280–420 px),
  в узком окне сворачивается до аватаров.
- **Чат:** шапка в одну строку, действия появляются при наведении.
  Поле ввода парит над лентой отдельной капсулой.
- **Панель профиля** выезжает справа и не сдвигает ленту, если окно широкое.
- Своя рамка окна — опция. По умолчанию окно отдаётся оконному менеджеру,
  чтобы корректно работать в тайлинговых окружениях.

## Фирменные элементы

- **Ореол.** Сегментированное кольцо из логотипа:
  - индикатор загрузки — вращающееся кольцо с разрывами;
  - «в сети» — тонкая дуга вокруг аватара;
  - включённый Ghost Mode — ореол вокруг своего аватара гаснет до пунктира.
- **Зерно.** Статичная текстура шума с непрозрачностью 3–4 % на фоне окна,
  пустых экранах и Message Shot. Рисуется один раз и тайлится.
- **Пустые состояния** — силуэт из логотипа и одна строка текста.

## Движение

| Токен | Длительность | Кривая | Где |
| --- | --- | --- | --- |
| `motion.quick` | 90 мс | OutCubic | наведение, нажатие |
| `motion.standard` | 160 мс | OutCubic | появление сообщений, меню |
| `motion.emphasized` | 240 мс | OutQuint | панели, смена экранов |

- Новое сообщение: прозрачность 0 → 1 и подъём на 4 px.
- Без пружин и подпрыгиваний.
- Настройка «уменьшить движение» сводит все длительности к нулю.

## Иконки

Собственный набор: сетка 20 px, линия 1.5 px, скругленные окончания.
Заливка — только для активного состояния.

## Доступность

- Контраст основного и вторичного текста не ниже WCAG AA в обеих темах.
- Видимое кольцо фокуса при работе с клавиатуры.
- Масштаб интерфейса от 80 до 150 %, независимо от системного.
