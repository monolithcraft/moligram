# Исследования

Разборы чужих клиентов и выводы для Moligram. Здесь только идеи и наблюдения,
никакого чужого кода.

- [AyuGram](ayugram.md) — форки официальных клиентов с функциями приватности
- [Monogram](monogram.md) — клиент для Android с нуля, протокол на Rust
- [Идеи для Moligram](ideas.md)

## Сравнение подходов

| | AyuGram | Monogram |
| --- | --- | --- |
| Основа | форк официального клиента | своё приложение + свой MTProto |
| Полнота функций Telegram | полная сразу | растёт постепенно |
| Чистота архитектуры | низкая: правки по всему upstream | высокая: модули и границы |
| Стоимость обновлений | высокая (конфликты при мерже) | своя, но предсказуемая |
| Функции приватности | очень много | почти нет |

## Варианты основы для Moligram

**A. Форк официального клиента** (Telegram Android или Telegram Desktop).
Самый быстрый путь к полноценному мессенджеру. Цена — чужая архитектура,
которую нельзя сделать «идеальной», постоянные конфликты при обновлениях,
GPL-3.0.

**B. Своё приложение на TDLib.** TDLib — официальная библиотека Telegram,
берёт на себя протокол, шифрование, синхронизацию и локальную базу
(с шифрованием ключом). Интерфейс и вся архитектура — полностью наши.
Функции приватности реализуются естественно: прочтение, статус в сети,
действия «печатает» и просмотр историй в TDLib вызываются явно,
значит их легко контролировать в одном месте.

**C. Своё приложение и свой MTProto** (как Monogram). Максимальный контроль,
но годы работы только на протокол.

**Решение: вариант B, первая платформа — Linux.** Он единственный даёт
одновременно чистую архитектуру с нуля, полную поддержку Telegram и разумные
сроки. Протокол и криптографию пишет и проверяет команда Telegram, мы
концентрируемся на интерфейсе, приватности и скорости.

Стек: C++23, Qt 6 Quick, TDLib. Подробности — в
[`docs/ARCHITECTURE.md`](../ARCHITECTURE.md).

## Риски, о которых стоит помнить

- Часть функций приватности (невидимка, сохранение удалённого) нарушает
  условия использования Telegram API. Telegram может отозвать `api_id`
  клиента, а в худшем случае — ограничить аккаунты. AyuGram открыто
  позиционирует себя так и живёт с этим риском. Решение нужно принять
  осознанно и описать в README.
- Лицензия: форк официальных клиентов обязывает к GPL-3.0. TDLib
  распространяется под Boost Software License, Qt — под LGPL-3.0
  (при динамической линковке), так что выбор лицензии за нами.
