# Идеи для Moligram

Всё обсуждаемо. У каждой идеи — проблема, которую она решает.
Названия известных функций оставлены общепринятыми.

## Приватность

**Ghost Mode.**
Отдельные переключатели: прочтение сообщений, прочтение историй, статус
«в сети», «печатает…», автоматический оффлайн. В отличие от аналогов:
- пресеты («полный», «только истории», «выключен») вместо десятка флагов;
- расписание: например, включается сам с 23:00 до 9:00;
- исключения по чатам: близким людям прочтения уходят всегда;
- Read on Interact: чат отмечается прочитанным, только когда вы
  в нём что-то сделали;
- все исходящие «следы» проходят через одну политику запросов, поэтому
  её легко проверить и покрыть тестами.

**Message History** (сохранение удалённых и изменённых).
Отдельная зашифрованная база, не связанная с кэшем TDLib. Правки
показываются как diff между версиями. Удалённое встраивается в ленту
по дате и ID, без потерь на стыках страниц, как у AyuGram.

**Streamer Mode.**
На Wayland приложение не может запретить захват своего окна, поэтому
делаем по-другому: при включении размываются номера телефонов, имена
вне текущего чата, превью уведомлений и счётчики. Режим можно включать
автоматически, когда запущен OBS или идёт трансляция экрана через портал.

**Vault** — скрытые чаты и папки за отдельным кодом.
Плюс ложный код: при его вводе открывается профиль без скрытого.

**Panic Key** — глобальное сочетание клавиш, которое мгновенно блокирует
приложение и прячет окно; по второму сочетанию — выход из аккаунтов
и стирание локальных данных.

**Чистые ссылки** — удаление трекинговых параметров (`utm_*`, `fbclid`, `si`
и т.п.) при отправке и открытии ссылок.

**Буфер обмена** — автоочистка скопированных кодов входа через заданное время.

## Удобство для десктопа

**Командная палитра** (`Ctrl+K`) — переход в любой чат, к настройке,
действию или сообщению по поиску. Главный способ навигации для тех,
кто не любит мышь.

**Клавиатура везде** — навигация по чатам и сообщениям без мыши,
ответ, пересылка, редактирование горячими клавишами, вся раскладка
настраивается.

**Два чата рядом** — разделённый вид для работы с двумя диалогами
одновременно.

**Фильтры с конструктором** — правила «скрыть, если…» собираются
из блоков (слово, отправитель, тип сообщения, есть кнопки). Для
продвинутых — регулярные выражения с ограничением времени выполнения,
чтобы одно кривое выражение не вешало чат.

**Перевод на устройстве** — локальные модели вместо отправки текста
внешнему сервису. Онлайн-переводчик — только по явному выбору.

**Message Shot** — экспорт сообщения или цепочки в картинку с темами
в стиле Moligram.

**Подтверждения отправки** — для стикеров, GIF, голосовых; по чатам.

**Тихие часы и дайджест** — уведомления из выбранных чатов копятся
и приходят одной сводкой.

**Профили настроек** — экспорт и импорт всех настроек одним файлом.

## Сеть

**Список прокси с автопереключением** — несколько MTProxy и SOCKS5,
клиент сам переходит на рабочий и показывает задержку каждого.

## Интеграция с Linux

- Нативный Wayland, дробное масштабирование, корректная работа в тайлинговых
  менеджерах (Hyprland, Sway): без обязательной своей рамки окна.
- Уведомления, выбор файлов, открытие ссылок — через XDG Desktop Portal.
- Ключ шифрования локальных данных — в системном хранилище секретов
  (Secret Service: GNOME Keyring, KWallet, KeePassXC).
- Значок в трее через StatusNotifierItem.
- Пакеты: Flatpak, AUR, AppImage.
